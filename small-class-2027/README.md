# Landing Page PTN Small Class 2027

Halaman ini merupakan bagian dari website utama dan dipublikasikan pada `/small-class-2027/`.

CSS dan JavaScript landing page sengaja tetap lokal di folder ini agar tidak berbenturan dengan tampilan halaman utama. Gambar dan konfigurasi kontak menggunakan aset bersama dari `../assets/`.

Jalankan server statis dari folder `main-website`, lalu buka `http://localhost:8080/small-class-2027/`.
